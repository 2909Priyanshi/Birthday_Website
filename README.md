# Birthday Website

A personalized, cinematic birthday experience built with React and Vite.

## Quick start

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Personalize

Edit `src/config/birthdayConfig.js` to change:

- Name and birthday date
- Opening / main / final messages
- Music path
- Memory photos and captions
- Theme colors

Place media files under:

- `public/assets/photos/`
- `public/assets/music/`

## Project structure

```
public/assets/photos/
public/assets/music/
src/components/
src/config/birthdayConfig.js
src/hooks/
src/utils/
src/styles/global.css
src/App.jsx
src/main.jsx
```
